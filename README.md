# Simple Line Editor in C

## About
A simple command-line text editor developed in C as part of Activity 7: Line Editor Competition.

## Features
- Insert a line of text
- Delete a line
- Display all lines with line numbers
- Store and manage document lines in memory

## Technologies Used
- C Programming
- GCC Compiler
- Git and GitHub

## File Structure
- `hello.c` — Basic C program
- `line_editor.c` — Line editor implementation
- `README.md` — Project documentation
- `HELP.md` — Instructions for using the line editor

## How to Compile and Run

Compile the program:

```bash
gcc line_editor.c -o line_editor
```

Run on Windows:

```bash
.\line_editor.exe
```
